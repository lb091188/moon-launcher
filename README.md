# moon-launcher

轻量原生跨平台桌面启动器 —— [native-gui](https://github.com/lb091188/moonbit-native-gui) 的旗舰应用。
宿主与界面全部自绘渲染，插件在子进程里只生产「数据与动作」。

一句话定位：**跨三平台（Windows / Linux / macOS）+ MB 级体积 + 原生自绘 + 中文 / 拼音 / IME 原生**。

## 路线图

| 阶段 | 内容 |
|---|---|
| **v1** | 基础功能内置（应用 / 浏览器历史 / 书签 / 最近文件 / 计算器）+ 子进程插件：宿主以终端命令方式运行插件，stdin/stdout 行协议交互（默认 TSV 档，结构档 TOML，见 [PROTOCOL.md](PROTOCOL.md)） |
| **v2** | 开放 UI 配置：插件声明视图树，宿主渲染；UI 事件回传插件，插件数据更新通知宿主 |
| **v3** | Vue 语法子集转译：`.vue` 单文件（模板子集）→ 生成 MoonBit → 编译 wasm 插件 |

## 快速开始

```sh
moon run . --target native
```

依赖全部来自 mooncakes 注册表（`NoahLiu/native-gui` + `NoahLiu/yoga-mbt`），无路径覆盖、无手工链接配置——本仓库自身就是「`moon add` 后零配置 `moon run`」的持续验证。跨仓库联调的本地路径约定见 `AGENTS.md`。

## 架构

```
┌─ 宿主（MoonBit / native-gui 自绘）──────────────┐
│ 热键唤起 · 搜索框/列表/主题/IME · 托盘驻留 · 自启 │
└──────────────┬──────────────────────────────────┘
        stdin 行协议 │ stdout 行协议
┌──────────────┴──────────────────────────────────┐
│ 插件（任意可执行：bash / Python / MoonBit→wasm） │
│ 只生产：条目 + 动作（v2 起可声明视图树）          │
└─────────────────────────────────────────────────┘
```

两条红线：

1. **插件只给意图，不给像素**——渲染、主题、布局全部宿主负责；
2. **即时交互本地化**——滚动 / 悬停 / 输入过滤由宿主内建控件完成，跨进程只走语义事件。

## 与 native-gui 的关系

native-gui 是 GUI 库（窗口 / 光栅化 / 控件 / 主题 / 系统集成），moon-launcher 是用它搭的应用：库验证「易上手」，启动器验证「大包大揽」。两个仓库独立发版，本仓库 README 与库 README 互相链接。
